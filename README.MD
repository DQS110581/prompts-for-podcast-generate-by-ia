ℹ️ **NOTE:** Este é o repositório tem por objetivo de gerar um podcast utilizando ferramentas de IA através de prompts mais trabalhados.

Utilizei uma esteira de prompts para gerar cada etapa do processo criativo.

## 💻 Tecnologias utilizadas no projeto

- [ChatGPT](https://chat.openai.com/): criação do roteiro 
- [ElevenLabs](https://beta.elevenlabs.io/): Geração do áudio;
- [Capcut](https://www.capcut.com/pt-br/): Edição do Áudio


## ✨ Como foi feito ?

- Roteiro gerado via chatgpt
- Audio gerado pela elevenLabs
- Ilustrações: Microsoft Copilot ChatGPT
- Capcut para tratar aúdio e adicionar sons de fundo
